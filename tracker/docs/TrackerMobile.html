태블릿에서 실험하기

  1. 영상 열기. 사진 보관함이나 파일 앱에서 영상을 선택하세요. 「Google Drive에서 선택」에서는 파일 선택기의 Google Drive 위치를 선택하세요. 기존 .trk / .trz 프로젝트도 열 수 있습니다.
  2. 길이 보정. 보정 막대의 양 끝을 실제 길이를 아는 물체에 맞추고 길이를 입력하세요. 좌표축 원점과 방향도 맞춰 주세요.
  3. 질점 추가. 「터치로 점 찍기」를 켜고 영상 속 물체를 프레임마다 터치하세요. 기존 점은 끌어서 수정할 수 있습니다.
  4. 결과 확인과 저장. Tracker의 그래프·표에서 위치와 속도를 확인하고, 「프로젝트 저장」으로 영상과 분석을 .trz 파일로 만드세요. 표 데이터는 Tracker의 내보내기 메뉴를 사용하세요. 생성된 파일은 「결과 다운로드」에서 다운로드하거나 공유할 수 있습니다.
홈 화면에서 앱처럼 열기

iPad Safari: 공유 → 「홈 화면에 추가」. Android Chrome: 메뉴 → 「홈 화면에 추가」. 첫 실행과 추가 기능을 불러올 때 인터넷 연결이 필요합니다.

Google Drive에서 파일 선택: Drive 앱에 로그인하세요. iPad에서는 파일 앱 → 둘러보기 → 편집에서 Google Drive를 켜세요. Android에서는 파일 선택기 왼쪽 메뉴에서 Drive를 선택하세요. 웹앱에는 Google 계정 로그인이나 Drive 자동 저장 기능이 없습니다.

아이폰은 가로 화면을 권장합니다. 영상은 H.264 MP4가 가장 호환성이 좋습니다. 카메라 설정 → 포맷 → 「높은 호환성」을 사용하세요. 슬로 모션·가변 프레임 영상은 시간 간격을 확인하고, 정량 분석에는 고정 프레임률 영상을 권장합니다.

다른 앱으로 전환하기 전 프로젝트를 저장하세요. 운영체제가 탭을 종료하면 저장하지 않은 분석은 사라질 수 있습니다. 파일 자동 저장과 완전한 오프라인 실행은 지원하지 않습니다.

예제는 30 fps 합성 영상입니다. 보정선은 1 m이며, 연직 가속도는 −1.8 m/s²로 설정했습니다.

영상·파일 가져오기

분석할 영상이나 기존 Tracker 프로젝트를 선택하세요.

Drive는 기기의 파일 선택기를 통해 열립니다. iPad는 파일 앱의 둘러보기에서 Google Drive를 활성화하고, Android는 파일 선택기 왼쪽 메뉴에서 Drive를 선택하세요.

파일과 분석 결과

생성된 프로젝트와 표 데이터를 기기에 다운로드하세요. 공유를 지원하는 기기에서는 다른 앱으로 보낼 수도 있습니다.
